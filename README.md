# LudoEducatif-Site

Site produit **Ludo Éducatif** (No Sage's Editor) — 32 clubs ludo-éducatifs pour les 5-11 ans.
Site statique GitHub Pages, calqué sur `AnimGest-Site`. Identité **verte** (charte éditeur : Anim'Gest=bleu, Cockpit'Gest=violet, Ludo=vert).

## Arborescence
- `index.html` — accueil profond (deux portes parents/enfants, principe, exemple, familles)
- `site.css` / `site.js` — charte verte partagée
- `parents/` — vectorisation parents (pédagogie, garanties, espace parents)
- `enfants/` — vectorisation enfants (choisis ton monde, cocardes) — tutoiement
- `univers/` — catalogue en 5 familles + fiches (poney-club, montagne-club, clinique-veterinaire)
- `philosophie/` — le modèle pédagogique
- `tarifs/` — tarifs, essai 5 jours, FAQ
- `CNAME` — ludoeducatif-site.no-sages-editor.com
